fold test cases, so the patient-leakage fix is invisible to it. 'folds-only'

identically to 'corrected'. A corrected-vs-legacy delta in this file is a
PREPROCESSING delta and contains no part of the leakage effect.

SECTION 3: INTERPRETATION
------------------------------------------------------------

Key Findings:

1. EMBEDDING SPACE COMPACTNESS
   Bio_ClinicalBERT: mean pairwise similarity = 0.8253, std = 0.0489
   BiomedBERT: mean pairwise similarity = 0.9267, std = 0.0338
   BlueBERT: mean pairwise similarity = 0.7160, std = 0.0648
   Biomedical BERT models embed medical diagnosis text into a
   relatively narrow region of the embedding space, producing
   high baseline similarities even between unrelated diagnoses.

2. MAX OPERATOR AMPLIFICATION
   Bio_ClinicalBERT: pairwise mean = 0.8253 -> per-patient MAX mean = 0.8502
   BiomedBERT: pairwise mean = 0.9267 -> per-patient MAX mean = 0.9463
   BlueBERT: pairwise mean = 0.7160 -> per-patient MAX mean = 0.7564
   With 1.7 diagnoses per patient on average,
   the Cartesian product contains ~3 pairs.
   Taking the MAX over this product dramatically inflates the
   effective similarity, pushing nearly all pairs above 0.6.

3. THRESHOLD SATURATION
   Bio_ClinicalBERT:
     >= 0.6: 100.00%
     >= 0.7: 100.00%
     >= 0.8: 89.47%
     >= 0.9: 9.52%
     >= 1.0: 1.89%
   BiomedBERT:
     >= 0.6: 100.00%
     >= 0.7: 100.00%
     >= 0.8: 100.00%
     >= 0.9: 99.06%
     >= 1.0: 1.89%
   BlueBERT:
     >= 0.6: 99.65%
     >= 0.7: 82.92%
     >= 0.8: 19.45%
     >= 0.9: 2.69%
     >= 1.0: 1.89%

   This explains the perfect F1 at threshold 0.6:
   virtually every patient pair has MAX similarity >= 0.6.
   The evaluation metric is saturated at that threshold and cannot
   discriminate between models.

4. IMPLICATIONS
   - The cosine grader (MAX over the Cartesian product of diagnosis
     descriptions) is too lenient for these encoders at 0.6.
   - The project's answer is --pipeline drg: an encoder-independent
     grader with no threshold knob at all. Re-run this script with it
     to see Section 2 collapse to 0/1.
